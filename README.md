# niri-dotfiles

My [niri](https://github.com/YaLTeR/niri) setup on CachyOS, using [Dux Shell](https://github.com/duxlabs-dev/dux-shell) (the `dms` shell) for the bar, launcher, notifications, lock screen and widgets. KDE Plasma stays installed alongside it; pick the session at login.

## What's here

```
.config/niri/config.kdl          main niri config (generated by `dms setup`, plus my edits)
.config/niri/custom.kdl          my personal overrides, loaded last
.config/niri/dms/*.kdl           Dux Shell's niri files (binds, layout, colors, outputs, ...)
.config/dms/settings.json        Dux Shell settings (bar layout, theme, desktop widgets)
.config/dms/plugins/systemTemps/ desktop widget: CPU/GPU/RAM/SSD temps and usage
.config/environment.d/           KDE theme for Qt apps under niri, and the KDE Wallet store for Claude Desktop
.local/bin/system-temps          script that feeds the System Temps widget
material-wallpaper.json          Dux Shell's generated Material wallpaper settings
pkgbuilds/cmatrix-git/           cmatrix built with CMake so it keeps a transparent background
```

## Install

Packages (CachyOS / Arch):

```sh
sudo pacman -S niri dux-shell quickshell xwayland-satellite \
  xdg-desktop-portal-gnome xdg-desktop-portal-gtk \
  matugen cava qt6-multimedia wtype i2c-tools \
  ttf-jetbrains-mono-nerd ttf-merriweather
```

Copy the files into your home folder:

```sh
git clone https://github.com/pembasmikuman/niri-dotfiles.git
cd niri-dotfiles
cp -r .config .local ~/
```

Enable the shell with niri and log into the **niri** session:

```sh
systemctl --user add-wants niri.service dms.service
```

The Material wallpaper lives in `~/.local/state/dms/session.json`; merge the two keys from `material-wallpaper.json` into that file (or recreate it in Settings → Wallpaper).

The System Temps widget shows the machine's hostname and detects its sensors: AMD (`k10temp`/`zenpower`) or Intel (`coretemp`) CPUs, NVIDIA (`nvidia-smi`) or AMD (`amdgpu`) GPUs, and NVMe/SATA drives. Intel integrated graphics report no temperature, so that row shows "--". Add it from Settings → Desktop Widgets.

## Personal tweaks

- **Monitor:** HDMI-A-1, 1920x1080 @ 144 Hz (`dms/outputs.kdl`)
- **Focus follows mouse**, without scrolling the view (`config.kdl`)
- **Looks:** 6px gaps, window shadows, 2px focus ring, 12px corners (`custom.kdl`)
- **kitty** goes 60% see-through when floating and unfocused (`custom.kdl`)

## Extra system tweaks (not files in this repo)

Hide the GNOME bits pulled in by `xdg-desktop-portal-gnome` (needed for screen sharing):

```sh
mkdir -p ~/.local/share/applications ~/.config/autostart
for f in org.gnome.Nautilus nautilus-autorun-software user-dirs-update-gtk xdg-desktop-portal-gnome; do
  printf '[Desktop Entry]\nType=Application\nName=%s\nNoDisplay=true\nHidden=true\n' "$f" > ~/.local/share/applications/$f.desktop
done
for f in localsearch-3 user-dirs-update-gtk; do
  printf '[Desktop Entry]\nType=Application\nName=%s\nHidden=true\n' "$f" > ~/.config/autostart/$f.desktop
done
systemctl --user mask localsearch-3.service localsearch-control-3.service localsearch-writeback-3.service user-dirs-update-gtk.service
```

Default apps:

```sh
xdg-mime default org.kde.dolphin.desktop inode/directory
xdg-mime default org.kde.gwenview.desktop image/png image/jpeg image/gif image/webp image/bmp image/tiff image/svg+xml image/avif
```

`gh` hangs after the browser login under niri (xdg-open stays attached to the browser), so open links with gio instead:

```sh
gh config set browser "gio open"
```

cmatrix with a transparent background:

```sh
cd pkgbuilds/cmatrix-git && makepkg -si
```
